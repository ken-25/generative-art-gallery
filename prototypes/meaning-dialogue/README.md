# ことばとかたち（ローカル試作）

前回の候補選択版を残した独立試作です。公開ビルドに含めず、既存作品・main・サイト導線を変更しません。

`npm run build` → `node scripts/meaning-preview.cjs` → 表示されたloopback URL。

好きなもの／大切なこと／任意の出来事 → 回答を引用した意味・関係の問い返し → 解釈と形を確認 → 確定して入力・結果JSON／STL／画像保存。JSONを開いて同一形を再現できます。戻って回答を変えると、それに依存する意味確認をやり直します。

自由文の理解・推論は実装していません。本人が明示する意味と関係だけを使用します。「近い選択肢がない」では限界を説明し、回答を保持したまま意味の確定・造形へ進みません。語彙辞書による推測、性格分類、文面ハッシュによる乱数・色分けはありません。同じ意味付けをした異なる文章は同じ形になります。本人固有の唯一性や自然な自由対話が成立したとの主張はできません。LLM接続は未実装・外部通信なし。この範囲で意味の確認と造形の関係を体験できますが、開かれた文章の解釈を含む構想を検証するには別方式の判断が必要です。

生成器 `meaning-relations/1`。確認済み意味から構造を直接決定します：落ち着き／出会い／つながりは輪の配置、日常との関わりは層数、大切さは中心半径、支え／両立しにくさ／行き来は橋・距離・環、出来事の再確認／変化は一本／分岐する枝。UIでこの対応を示し、心理診断として扱いません。生成に乱数やseedはありません。Three.js0.180.0と既存のローカルSTLExporterを再利用し、この試作用のgeometryを使います。STLは表示と同一geometryのメッシュ出力です。製造品質の評価は対象外です。

保存ファイルには本人の回答を含みます。自動保存・URL共有・外部送信はしません。代表例は架空で、私生活の開示は不要です。入力文字数／ファイルサイズ／生成器バージョン／結果の一致を検証し、不正ファイルでは現在の回答を保持します。

確認：`node --test scripts/meaning.test.mjs` / `node scripts/meaning-browser.cjs`。証跡はgit対象外の`evidence/meaning-dialogue/`。
