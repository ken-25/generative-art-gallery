# 答えから生まれる一枚（試作）

既存トップの追加入口。個人情報や自由入力を使わず、3問・各3択で作品を描く。
心理・性格の判定や予測は行わず、説明は選択から線と色への対応を書く。

## 固定する v1 の対応

- 歩幅: ゆったり → R=96,r=48,d=36 / 軽やかに → 96,32,52 / 大きく → 100,40,72。
- 重なり: 一本 / 三本 / 五本。曲線ごとに17度回す。
- 景色: 木漏れ日 → fern / 土 → clay / 夕空 → dusk。
- その他は `works/rolling-circles/generator.js` v1 の既定値。乱数・日時・端末情報は使わない。

回答マッピング v1 と既存の転がる円 v1 を再利用する。既存生成器は変更しない。
`answers/` の共有URLは既存ArtShareのformat=1,generator=1で3回答を保存する。
既存作品と同じく、今後の変更時もv1のURLを同じ結果に復元すること。
新しい対応は別版に分け、共有の版ディスパッチを追加し、既存fixtureは更新しない。
SVGには元の生成器の設定と、回答・マッピングの版をmetadataに残す。

保存・共有・コピーは `assets/share.js` の既存ダイアログを利用。リセットは最初の回答へ戻る。
回答はURLフラグメントと書き出したSVGに含まれる。外部API・新規計測・保存先は追加しない。

元の数式・出典・利用条件は [転がる円の制作記録](../works/rolling-circles/DESIGN.md) と共通利用条件を参照。
新しい第三者画像・ライブラリは追加していない。

検証: 27組合せの共有URL/SVGハッシュを `scripts/fixtures/answers-v1.json` に固定。
Nodeテストで不正値・欠落・余分な項目・不正版を確認。ブラウザではサブパス、375/1440px、
キーボード、共有復元、PNG/SVG、コピー、リセット、旧作品への戻りを確認する。
