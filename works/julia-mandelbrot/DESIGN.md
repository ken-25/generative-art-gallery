# 作品の設計

## 数理と設定

複素二次多項式 f(z) = z² + c の反復で、パラメータ平面（Mandelbrot集合）と初期値平面（Julia集合）を並べて描きます。

- 左：表示範囲 実部 −2.1〜0.9、虚部 −1.5〜1.5（固定）。各マスの中心をcとし、z₀ = 0から反復します。逃走半径は2です。
- 右：表示中心と拡大率から半幅 1.6/拡大率 の正方形を表示し、各マスの中心をz₀として選んだcで反復します。逃走半径は max(2, |c|) とし、|c| > 2 のcでも逃げた点を正しく判定します。
- 判定：|z|² が逃走半径の2乗を超えた反復回数nを記録し、最大反復数まで超えなければ内側（n = 0）とします。有限反復による近似です。
- 格子：各面200×200マス（1マス2単位）。行ごとに計算し、8行ごとに処理を区切るため、ブラウザでは描画の合間に計算を分割し、設定が変わると古い計算を中断します。
- 描画：内側は1色、逃げた点は log n / log(最大反復数) を10段階に分けて背景色から線の色へ補間します。各行で同じ段階の連続するマスを1つの矩形にまとめ、段階ごとに1本のpathで描きます。左の図には選んだcに十字を描きます。

cの実部・虚部、右の図の表示中心と拡大率、最大反復数、配色を操作できます。乱数は使わないためseedはありません。

生成器v1の既定値・正規化・描画結果は、保存済み共有URLとSVGのfixtureで検証します。
