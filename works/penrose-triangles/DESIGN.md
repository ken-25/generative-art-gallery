# 作品の設計

## 数理と設定

黄金三角形（Robinson三角形）の置換によって、Penroseタイリング（菱形版）の有限パッチを三角形のまま描きます。

- タイル：頂点A（頂角）、B、Cの三角形。鋭（頂角36°、辺比 1 : 1 : 1/φ）と鈍（頂角108°）の2種類。φ = (1 + √5)/2。
- 置換：鋭 (A, B, C) → P = A + (B − A)/φ として 鋭 (C, P, B)、鈍 (P, C, A)。鈍 (A, B, C) → Q = B + (A − B)/φ、R = B + (C − B)/φ として 鈍 (R, C, A)、鈍 (Q, R, B)、鋭 (R, Q, A)。子は親を隙間なく分割するため、面積の合計が保たれます。
- 初期パッチ：中心のまわりに鋭い三角形10枚を、交互に鏡像にして並べた十角形（半径 600 × 表示範囲）。
- 枚数：鋭a・鈍bは1回で (a + b, a + 2b) になります。深さ7で全体6,100枚です。画面外の三角形は子も画面外なので、分割前に取り除きます。
- 描画：種類ごとに1本のpathで塗り、輪郭線は背景色で描きます。菱形への統合は行いません。

置換の深さ（0〜7）、回転、表示範囲、輪郭線の太さ、配色（2種のタイルの色）を操作できます。乱数は使わないためseedはありません。

生成器v1の既定値・正規化・描画結果は、保存済み共有URLとSVGのfixtureで検証します。
