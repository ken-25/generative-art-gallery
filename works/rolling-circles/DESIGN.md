# 作品の設計

## 数理と設定

半径Rの固定円の内側を半径rの円がすべらずに転がるとき、転がる円の中心から距離dの点が描く内トロコイドを計算します。

- 式：x = (R − r)cos t + d·cos((R − r)t / r)、y = (R − r)sin t − d·sin((R − r)t / r)。
- 周期：R、rを正の整数に限り、g = gcd(R, r) として t ∈ [0, 2πr/g] で閉曲線になります。d = 0 のときは描点が転がる円の中心で、半径 R − r の円を1周で閉じるため、t ∈ [0, 2π] とします。終点は t = 2πr/g を直接計算し、浮動小数の積み残しで閉じ損ねないようにします。
- 分割数：点の速さの上限 (R − r) + d(R − r)/r と画面上の拡大率から、隣り合う点が約2単位になる数を求め、96〜6,000点に制限します。重複する周回は描きません。
- 拡大率：最大半径 (R − r) + d が270単位になるよう拡大し、中心(450, 300)に置くため、全軌跡がviewBox内に収まります。
- r ≥ R は拒否し、線を描かずに理由を表示します。r = 0 などの範囲外の値は正規化で最小値1に補正します。

固定円の半径・転がる円の半径・描点の距離・回転・曲線の数・曲線ごとの位相差・線幅・配色を操作できます。乱数は使わないためseedはありません。

生成器v1の既定値・正規化・描画結果は、保存済み共有URLとSVGのfixtureで検証します。
