# 作品の設計

## 数理と設定

Gray–Scottモデルを格子上で陽的に時間発展させ、物質Bの濃度の等値線を描きます。

- 式：A' = A + D_A∇²A − AB² + F(1 − A)、B' = B + D_B∇²B + AB² − (K + F)B。
- 生成器仕様（v1で固定）：150×100の周期境界の格子、D_A = 1、D_B = 0.5、時間刻み1。∇²は3×3の重み（上下左右0.2、斜め0.05、中央−1）。各ステップの値を[0, 1]に制限して有限値を保ちます。
- 初期状態：全体をA = 1、B = 0とし、seedから決めた位置に7×7セルの種（A = 0.5、B = 1）を置きます。
- プリセット：斑点（F = 0.0367, K = 0.0649）、迷路（F = 0.029, K = 0.057）、珊瑚（F = 0.0545, K = 0.062）。「値を指定」ではF 0.01〜0.1、K 0.04〜0.07を選べます。
- 計算量：反復は最大4,000回（Node.jsで約0.8秒を実測）。20回ごとに処理を区切り、ブラウザでは描画の合間に分割して計算し、設定が変わると古い計算を中断して表示を上書きしません。閾値と配色だけの変更では再計算しません。
- 輪郭：格子の外側を0で埋めたうえでマーチングスクエア法により閾値の等値線を求め、辺上の交点を線形補間します。鞍点ではセルの平均値で接続を決めます。全輪郭は閉じた多角形になり、偶奇規則で塗るため、プレビューと保存SVGは同じpathを使います。閾値を超える領域がなければ輪郭なしとして正常に扱います。

模様、給餌率、除去率、初期種の数、反復回数、輪郭の閾値、配色、seedを操作できます。

生成器v1の既定値・正規化・描画結果は、保存済み共有URLとSVGのfixtureで検証します。
